# Accepted Requirements

## R-001 — Project language

**Status:** Accepted

The root README and the game client must be written in English.

### Consequences

- Player-facing client text is written in English.
- Game terminology exposed by the client is defined in English.
- Project Nutcracker documentation is maintained in English for consistency.
- Conversation with the project owner may use another language.

## R-002 — Evolutionary playable development

**Status:** Accepted

The first playable version must be the beginning of the final game rather than
a disposable prototype. Subsequent work expands and refines that playable
version continuously.

### Consequences

- Early implementation must be maintainable enough to evolve.
- Each increment should leave the game in a coherent, playable state.
- Experiments should normally be implemented as refinements or narrow slices of
  the final design.
- A disposable experiment requires an explicit reason and decision.
