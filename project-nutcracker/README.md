# Project Nutcracker

Project Nutcracker is the decision-guided development process for Army Manager
Arcade. It turns an incomplete idea into a working product by identifying the
most consequential unresolved question, offering concrete choices, recording
the decision, and continuing the work that follows from it.

This directory is the durable memory of that process. It should stay concise
and useful to both the project owner and an agent joining the project later.

## Working entry point

The recurring prompt is:

> What comes next?

The answer must provide exactly four high-weight current topics and recommend
one of them. After the owner selects a topic, the next step presents exactly
four meaningful solution choices for that topic.

See [PROCESS.md](PROCESS.md) for the ranking and decision rules.

## Documents

- [REQUIREMENTS.md](REQUIREMENTS.md) contains accepted, durable requirements.
- [DECISIONS.md](DECISIONS.md) records choices and their consequences.
- [PROCESS.md](PROCESS.md) defines how work is selected and decisions are made.
- [COMBAT.md](COMBAT.md) contains the accepted combat model and its open edges.
- [ECONOMY.md](ECONOMY.md) contains accepted resources, rewards, and ownership
  rules.
- [NEXT.md](NEXT.md) is the small, current project frontier. It is rewritten as
  the project changes rather than used as an exhaustive backlog.

## Language

The root README, this project process, and the game client are maintained in
English. Conversation with the project owner may use their preferred language.
